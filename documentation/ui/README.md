# UI

The frontend (`frontend/`) is a Vue 3 app with three main screens (roulette, watchlist, import) and the pages for editing a film and choosing its TMDB match. Each feature has its own chapter, listed in the [documentation index](../README.md#ui).

Requirements for all UI: WCAG 2.2 level AA, with the TMDB attribution visible (see [TMDB enrichment](../backend/tmdb-enrichment.md#attribution) and [TMDB attribution](tmdb-attribution.md)).
